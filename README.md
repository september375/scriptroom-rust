# Scriptroom 3.1 – Rust Edition

A lightweight, literary-inspired screenplay library for Windows.

**Features**
- Rust-powered desktop application using Tauri.
- Novel-inspired user interface.
- Dark and parchment themes.
- Custom PDF reader.
- Eco rendering mode for older hardware.
- Supabase cloud storage.
- Secure administrator access.

**System requirements**
- Windows 10 or 11 (64-bit).
- Microsoft Edge WebView2 Runtime.
- Internet connection.

Download and run the Windows installer to get started.
